ChoctoTip Commands

General Commands

/airdrop

Create an airdrop for other users to claim

  • asset - The currency to airdrop
  • amount - The total amount to airdrop. type 'all' to airdrop entire balance of asset.
  • duration - Duration (e.g., '30s', '5m', '1h')

/convert

Convert USD Value to Token Value

  • amount - USD Value to Convert
  • asset

/deposit

Deposit Crypto into your tip wallet

  • asset

/faucet

Claim Guild Faucet

/help

How to use ChoctoTip

/phrasedrop

Start a phrase drop

  • phrase - The phrase you want to drop
  • amount - The amount of currency you want to tip
  • asset - The currency you want to tip
  • duration (optional) - Duration (between 10s and 5m)

/price

show the price of a token on the bot in USD.

  • asset

/question

Create a trivia question

  • amount
  • asset
  • duration (optional) - Duration of the question (e.g., 60s, 3m)

/tip

Tip another user or role from your tip wallet balance

  • recipient - The user or role you want to tip
  • amount - The amount to send. For roles, this is the total amount to be split unless 'each' is True.'all' sends all of the asset from your tip balance.
  • asset - The currency you want to tip in
  • each (optional) - [Roles Only] If True, send the specified amount to EACH user in the role.

/tipactive

Tip all users active in this channel over a set duration.

  • amount - The amount to distribute (total or per-user depending on 'each'). 'all' tips entire balance of asset.
  • asset - Which token to tip
  • duration - How far back to check for activity (e.g., 30s, 5m, 1h)
  • each (optional) - If True, sends the specified amount to EACH active user instead of splitting

/tipbalance

Check your tip wallet balance

/verify_twitch

Connect your twitch account to discord for payouts!

/withdraw

Withdraw supported tokens from your tip balance

  • asset - The asset you want to withdraw
  • amount - The amount to withdraw, or type 'all' to withdraw your full balance
  • address - The Solana wallet address to send to

/withdraw_guild_balance

Withdraw tokens from the guild's tip balance (Affiliate Only)

  • asset - Which token to withdraw
  • amount - Amount to withdraw (number or 'all')

Administrator Commands

/check_bot_balance

Check the bot's wallet balance

Server administrator only.

/set_faucet_amount

Set Faucet Amount

Server administrator only.

  • amount - Amount paid for each successful faucet claim.

/set_faucet_duration

Set Faucet Cooldown

Server administrator only.

  • hours - Number of hours users must wait between faucet claims.

/set_faucet_enabled

Set Faucet Enabled

Server administrator only.

  • state - Enable or disable faucet claims in this server.

/set_faucet_token

Set Faucet Token

Server administrator only.

  • token - Token paid out for each faucet claim.

/set_server_affiliate

Set Server Affiliate

Server administrator only.

  • member - Server affiliate has the ability to remove tokens from the guild tip bot balance.

/settings

Configure tip-related settings

Server administrator only.
